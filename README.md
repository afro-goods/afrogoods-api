## AfroGoods API — Quick start

Minimal instructions to run the NestJS backend locally.

Prerequisites

- Node.js 18+
- pnpm (recommended) or npm/yarn
- MongoDB (local or remote) — used by the app
- Redis (local or remote) — used for job queues (workers are optional)

1. Install dependencies

```bash
pnpm install
```

2. Provide environment variables

Create a `.env` file in the project root (or set env vars in your shell). At minimum set:

- DATABASE_URI (e.g. mongodb://localhost:27017/afrogoods)
- JWT_SECRET (any string for dev)
- PORT (optional, default in code)
- REDIS_HOST and REDIS_PORT (if you plan to run workers)

Example `.env` (development):

```text
DATABASE_URI=mongodb://localhost:27017/afrogoods
JWT_SECRET=dev_secret
PORT=3000
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
NODE_ENV=development
```

3. Run in development (watch mode)

```bash
pnpm start:dev
```

4. Build and run production

```bash
pnpm run build
pnpm run start:prod
```

Tests

```bash
pnpm run test
```

Notes

- Workers are in `src/workers/` and use BullMQ; you only need Redis to run them.
